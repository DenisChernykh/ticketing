# 9. Освобождение просроченной брони

[Все задачи](../../README.md#tasks)

**Задача.** Покупатель забронировал места и не оплатил заказ. Места нужно вернуть в продажу, даже если работают несколько фоновых обработчиков.

**Решение.** Сохранить срок брони в заказе. Worker находит просроченные брони и для каждой заново проверяет состояние под блокировкой. Переход в `expired` и возврат мест происходят одной транзакцией, поэтому повторная обработка не возвращает места дважды.

**Код решения:**

- [CheckoutService.purchase()](../../apps/sales/src/modules/checkout/application/checkout.service.ts#L23) — задаёт срок брони: десять минут, максимум до начала мероприятия.
- [PgOrders.due()](../../apps/sales/src/modules/orders/infrastructure/pg-orders.ts#L60) — выбирает кандидатов на освобождение.
- [CheckoutService.expire()](../../apps/sales/src/modules/checkout/application/checkout.service.ts#L116) — блокирует каждый заказ, повторно проверяет срок и завершает бронь.
- [Sales worker](../../apps/sales/src/bootstrap/worker.ts#L22) — периодически запускает освобождение броней.

**Проверки:**

- [Два worker](../../test/integration/lifecycle.test.cjs#L157) — освобождают просроченную бронь один раз; попытка оплаты после истечения не возобновляет её.
