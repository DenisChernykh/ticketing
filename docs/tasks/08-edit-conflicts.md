# 8. Защита от перезаписи изменений

[Все задачи](../../README.md#tasks)

**Задача.** Две вкладки открыли одно мероприятие. Вторая сохраняет устаревшие данные и может затереть изменения первой.

**Решение.** Отправлять текущую `version` вместе с PATCH. Под блокировкой строки сравнить её с версией в БД. При совпадении сохранить изменения и увеличить версию; при несовпадении вернуть `409 EVENT_VERSION_CONFLICT`.

**Код решения:**

- [PgCatalog.update()](../../apps/sales/src/modules/catalog/infrastructure/pg-catalog.ts#L46) — блокирует мероприятие, проверяет владельца и версию, затем сохраняет изменения.
- [UPDATE мероприятия](../../apps/sales/src/modules/catalog/infrastructure/pg-catalog.ts#L70) — увеличивает `version` вместе с записью новых значений.

**Проверки:**

- [Два одновременных PATCH](../../test/integration/lifecycle.test.cjs#L110) — с одной версией дают один `200` и один `409`; сохранённая версия увеличивается до 2.
